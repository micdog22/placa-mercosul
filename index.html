Placa Mercosul

Valide placas de veículos brasileiras e converta entre o padrão antigo e o Mercosul.

Digite a placa

Padrão antigo (ABC-1234) ou Mercosul (ABC1D23). Espaços, hífens e pontos são ignorados.

As duas versões da placa

Como a conversão funciona

Na passagem para o padrão Mercosul só o 5º caractere muda: o segundo número da placa antiga vira uma letra. O resto continua igual, então ABC-1234 passa a ser ABC1C34.

Número da placa antiga e letra correspondente no padrão Mercosul
Número0123456789
LetraABCDEFGHIJ

Placas Mercosul com uma letra de K a Z nessa posição foram emitidas já no padrão novo e não têm versão no padrão antigo. A placa Mercosul também não indica o estado nem a cidade do veículo.

Use no seu projeto

Biblioteca JavaScript sem dependências, para Node.js e navegador, com linha de comando.

npm install github:micdog22/placa-mercosul

import { validar, paraMercosul, paraAntiga } from 'placa-mercosul';

validar('abc-1234');      // { valida: true, formato: 'antiga', placa: 'ABC1234', motivo: null }
paraMercosul('ABC-1234'); // 'ABC1C34'
paraAntiga('ABC1C34');    // 'ABC1234'
paraAntiga('ABC1K34');    // null (emitida já no padrão Mercosul)
